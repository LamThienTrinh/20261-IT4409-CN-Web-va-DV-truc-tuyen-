# 20261-IT4409-CN-Web-va-DV-truc-tuyen-

Website học liệu và bài tập môn Công nghệ Web và Dịch vụ trực tuyến IT4409 của **Trịnh Thiên Lam — MSSV 20235359**.

## Các Assignment

- Assignment 01: domain, hosting và Git/GitHub.
- Assignment 02: kiểm tra lỗi HTML, form đăng ký, media và semantic HTML5.
- Assignment 03: ba bài thực hành về sửa lỗi CSS Box Model, Position và thiết kế responsive.
  - Bài 3: `public/bai-tap/assignment-03/bai-3/responsive.html` — 3 cột từ 1024px, 2 cột từ 600px đến dưới 1024px, 1 cột dưới 600px.
- Assignment 04: xây dựng giao diện CSS responsive cho trang giới thiệu Blakletterpress mà không thay đổi HTML gốc.
- Bài 4 · Buổi 4: ba bài JavaScript về lập phiếu in, tin tức và giỏ hàng JSON, thư viện ảnh và tin nhanh qua DOM.
  - Tổng quan: `public/bai-tap/asignment4-baisau/index.html`.
  - Bài 1a: `public/bai-tap/asignment4-baisau/bai-1/index.html`.
  - Bài 1b và bộ kiểm tra: `public/bai-tap/asignment4-baisau/bai-1/about.html`.
  - Bài 2a tin tức JSON: `public/bai-tap/asignment4-baisau/bai-2/news.html`.
  - Bài 2b giỏ hàng và 20 kiểm tra: `public/bai-tap/asignment4-baisau/bai-2/index.html`.
  - Bài 3a thư viện ảnh: `public/bai-tap/asignment4-baisau/bai-3/index.html`.
  - Bài 3b tin nhanh và 18 kiểm tra: `public/bai-tap/asignment4-baisau/bai-3/news-wrapper.html` (bao ngoài `news.html` giữ nguyên theo đề).

Các trang deploy nằm trong `public/bai-tap/assignment-01`, `assignment-02`, `assignment-03`, `assignment-04` và `asignment4-baisau`.
