Website học liệu và bài tập môn Công nghệ Web và Dịch vụ trực tuyến IT4409 của **Trịnh Thiên Lam — MSSV 20235359**.

## Các Assignment

- Assignment 01: domain, hosting và Git/GitHub.
- Assignment 02: kiểm tra lỗi HTML, form đăng ký, media và semantic HTML5.
- Assignment 03: ba bài thực hành về sửa lỗi CSS Box Model, Position và thiết kế responsive.
  - Bài 3: `public/bai-tap/assignment-03/bai-3/responsive.html` — 3 cột từ 1024px, 2 cột từ 600px đến dưới 1024px, 1 cột dưới 600px.
- Assignment 04: xây dựng giao diện CSS responsive cho trang giới thiệu Blakletterpress mà không thay đổi HTML gốc.

Các trang deploy nằm trong `public/bai-tap/assignment-01`, `assignment-02`, `assignment-03` và `assignment-04`.
