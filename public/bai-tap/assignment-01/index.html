02 · Trình tự thực hiện

Làm lần lượt

  1. Đọc Assignment 01

    Mở tài liệu gốc, ghi lại ba việc phải hoàn thành: domain, hosting và repository.

  2. Chuẩn bị repository GitHub

    Tạo repo, cấu hình danh tính commit local, gắn remote, commit và push mã nguồn. Repo của dự án này ↗ đã có trên GitHub.

  3. Triển khai website trên hosting

    Import repo vào Vercel, chọn cấu hình trang tĩnh và bấm Deploy. Trang Vercel của dự án ↗ đã mở được. Xem thêm hướng dẫn Vercel.

  4. Đăng ký tên miền miễn phí

    Chọn tên miền còn khả dụng, kiểm tra điều kiện miễn phí tại nhà đăng ký và hoàn tất đăng ký bằng tài khoản của bạn. Lưu lại tên miền và nơi quản lý DNS.

  5. Trỏ tên miền về Vercel

    Thêm domain trong Project → Settings → Domains, cấu hình đúng bản ghi DNS Vercel yêu cầu, chờ xác minh rồi mở tên miền của dự án ↗ để kiểm tra HTTPS và nội dung trang.
