Git và GitHub

Các khái niệm và lệnh cần dùng để lưu trang môn học vào repository và cập nhật phiên bản trên GitHub.

Bốn thứ cần phân biệt

1

Thư mục làm việc

File bạn đang sửa trên máy, ví dụ public/index.html.

2

Commit

Mốc lưu một nhóm thay đổi trong lịch sử Git local.

3

Remote

Repository GitHub được gắn với tên origin.

Danh tính user.name và user.email xuất hiện trên commit. Việc đăng nhập GitHub để push là bước xác thực riêng.

Quy trình cập nhật website

Repository môn học đã được khởi tạo. Mỗi lần sửa tài liệu hoặc bài tập, dùng các lệnh sau trong thư mục dự án:

git status
git add public/
git commit -m "Cap nhat hoc lieu"
git push origin main

git add public/ chỉ đưa nội dung website vào commit. Hãy xem git status trước khi commit để biết chính xác file nào sẽ được đẩy lên.

Kiểm tra kết quả

  • Mở repository môn học trên GitHub và xem commit mới trên nhánh main.
  • Sau khi GitHub nhận commit, project Vercel kết nối với repo sẽ tạo bản deploy mới.
  • Mở website để kiểm tra nội dung hiển thị đúng.

Trang này là ghi chú thực hành cho dự án. Tài liệu chính thức: GitHub Docs ↗.
