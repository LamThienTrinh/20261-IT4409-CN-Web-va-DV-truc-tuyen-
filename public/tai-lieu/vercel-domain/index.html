Vercel và tên miền

Đưa website tĩnh lên Vercel, sau đó kết nối một tên miền tự đăng ký nếu bài tập yêu cầu.

1. Triển khai trang tĩnh

  1. Import repository

    Vào Vercel New Project ↗, đăng nhập GitHub và chọn repo môn học.

  2. Kiểm tra cấu hình

    Chọn Framework Preset Other, Root Directory ./, để trống Build Command và dùng thư mục đầu ra public.

  3. Deploy và mở trang

    Bấm Deploy. Khi trạng thái là Ready, mở URL *.vercel.app để kiểm tra trang chủ và các mục điều hướng.

Tham khảo: Deploy từ Git và cấu hình build của Vercel.

2. Kết nối tên miền riêng

URL *.vercel.app là địa chỉ Vercel cấp cho bản deploy. Đề Assignment 01 còn có mục đăng ký tên miền miễn phí riêng.

  1. Đăng ký tên miền

    Chọn một nhà đăng ký. Đề bài đưa liên kết tham khảo tới P.A Việt Nam và Mắt Bão; xem điều kiện hiện tại trước khi đăng ký.

  2. Thêm domain vào project

    Trong Vercel, vào Project → Settings → Domains → Add Domain và nhập tên miền bạn sở hữu.

  3. Thiết lập DNS

    Sao chép đúng bản ghi A, CNAME hoặc TXT mà Vercel hiển thị, rồi thêm ở nơi bạn quản lý DNS. Chờ Vercel xác minh và thử mở tên miền qua HTTPS.

Giá trị DNS có thể khác giữa các project. Hãy dùng giá trị trên dashboard Vercel của chính bạn thay vì chép một IP mẫu từ hướng dẫn khác.
